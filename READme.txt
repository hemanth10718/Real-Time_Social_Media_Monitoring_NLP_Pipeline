# TraceGuard: Social Media Text Analyzer

A Flask web app that reads recent public posts from a social media source, compares the text to a reference set using TF-IDF and cosine similarity, and generates a PDF report with an AI-written summary and a word cloud.

> **Intended use:** education and research on public content only. The score measures word overlap with a reference set you provide. It is **not** evidence about any person or channel. Do not use this project to surveil, profile or target individuals.

## Features

- **Telegram collection:** reads the latest messages from a public channel (tested end to end).
- **Instagram and X (Twitter) collectors:** included as optional modules, but not tested (see [Platform status](#platform-status)).
- **Text cleaning:** strips Markdown links, URLs, formatting characters and non-ASCII text before analysis.
- **Similarity scoring:** TF-IDF vectors plus cosine similarity against a reference CSV, shown as a percentage.
- **PDF report:** title, score, a short summary generated by `facebook/bart-large-cnn`, and a word cloud of frequent terms.
- **Web dashboard:** simple Flask pages for each platform and a report page with a download button.

## How it works

```
Collect public posts  ->  Clean text  ->  TF-IDF + cosine similarity vs. reference set
                                      \->  BART summary + word cloud  ->  PDF report
```

1. A platform function (`scrape_telegram`, `scrape_twitter`, `scrape_instagram`) returns a pandas DataFrame with a `text` column.
2. `clean_text` removes links, URLs, asterisks and non-ASCII characters.
3. `check_suspicious` (an internal name kept from the original code) computes the similarity score between the collected text and `reference_data.csv`.
4. `generate_nlp_report` summarizes the text, builds a word cloud and writes the PDF.

## Tech stack

Flask, pandas, scikit-learn, Hugging Face Transformers + PyTorch (`facebook/bart-large-cnn`), wordcloud, fpdf2, Telethon, tweepy, instaloader, python-dotenv.

## Setup (Windows PowerShell)

**Requirements:** Python 3.11 or 3.12. Python 3.13 fails on the pinned `pandas==2.0.3`.

```powershell
git clone https://github.com/hemanth10718/Real-Time_Social_Media_Monitoring_NLP_Pipeline
cd Real-Time_Social_Media_Monitoring_NLP_Pipeline\"Trace Guard"
py -3.11 -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

If PowerShell blocks the activation script, run this once for the current session:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### Configure credentials

Create a file named `.env` inside the `Trace Guard` folder. It is listed in `.gitignore`, so it is never committed.

```
FLASK_SECRET_KEY=<random string>
TELEGRAM_API_ID=<from my.telegram.org>
TELEGRAM_API_HASH=<from my.telegram.org>
TELEGRAM_SESSION=<created in the next step>

# Optional (untested modules)
INSTAGRAM_USERNAME=
INSTAGRAM_PASSWORD=
TWITTER_BEARER_TOKEN=
```

Generate a secret key with:

```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

**Never commit `.env` or paste its contents anywhere public.**

### Telegram setup

1. Log in at <https://my.telegram.org>, open **API development tools**, create an app and copy the `api_id` and `api_hash` into `.env`.
2. Run the one-time login. It asks for your phone number (international format, for example `+91XXXXXXXXXX`) and the code Telegram sends to your app, then stores a session string in `.env`:

```powershell
python -c "import os; from dotenv import load_dotenv; from telethon.sync import TelegramClient; from telethon.sessions import StringSession; load_dotenv(); c=TelegramClient(StringSession(), int(os.getenv('TELEGRAM_API_ID')), os.getenv('TELEGRAM_API_HASH')); c.start(); open('.env','a').write('\nTELEGRAM_SESSION='+c.session.save()+'\n'); c.disconnect(); print('saved')"
```

The session string gives access to that Telegram account. Treat it like a password, and consider using a spare account. You can end the login any time in Telegram under **Settings > Devices**.

### Run

```powershell
python app.py
```

Open <http://127.0.0.1:5000/telegram>, enter a **public** channel such as `@telegram`, set a small limit (for example 5) and click **Analyze**.

The first report downloads the summarization model (about 1.6 GB). It is cached afterwards.

## Reference data

`reference_data.csv` contains a few made-up sentences so the project runs out of the box. The score is only as meaningful as the reference set, so replace it with your own text. Both the collected data and the reference file need a `text` column.

## Limitations

- The score is lexical overlap (TF-IDF), not semantic understanding, and it says nothing about intent or behavior.
- The summary uses only the first 1,024 characters of the collected text, and BART is tuned for news articles, so results on informal text can be rough.
- Collectors are rate-limited by the platforms. Keep volumes low.
- The Flask server runs in debug mode for local development only. Do not deploy it as is.

## Privacy and ethics

- Only public content is collected, and only in small amounts.
- Collected posts are written to a temporary CSV that is deleted right after analysis. Only the generated PDF stays on disk.
- Do not use this tool to identify, profile or target individuals.
- Follow each platform's terms and API policies.

## Security notes

- All credentials come from environment variables loaded from `.env`. Nothing sensitive belongs in source code.
- `.gitignore` excludes `.env`, `venv/`, `*.session`, generated reports and test files.
- If a key is ever exposed, revoke it at the source (platform developer console) rather than only deleting it from the code.
